# Cryptography and Secure Communications

## Overview

This repository contains practical cryptography and secure-communications laboratory work completed using Kali Linux and Python. The projects demonstrate the application of cryptographic concepts through hands-on exercises, command-line tools, Python implementations, and practical security testing.

The work covers both symmetric and asymmetric cryptography, cryptographic hashing, password security, digital signatures, certificates, public-key encryption, key exchange, and TLS.

The laboratory activities were completed in controlled educational environments for cybersecurity learning and practical skills development.

---

## Projects

### 1. Symmetric Cryptography and Hashing

**File:** `Symmetric-Cryptography-and-Hashing.pdf`

This project focuses on symmetric cryptography, classical ciphers, cryptographic hashing, password security, and message authentication.

Topics demonstrated include:

- Caesar Cipher
- Vigenère Cipher
- AES-128-CBC
- AES-256-ECB and AES-256-CBC comparison
- AES-256-GCM
- Password-based key derivation using PBKDF2
- Secure file encryption and decryption
- SHA-256 hashing
- File integrity verification
- Cryptographic avalanche effect
- HMAC-SHA256
- bcrypt password hashing
- Rainbow table concepts
- MD5 collision vulnerabilities
- Python hash-table implementation
- Cryptographic hashes in Git and version control

### 2. Asymmetric Cryptography, Digital Signatures and TLS

**File:** `Asymmetric-Cryptography-Digital-Signatures-and-TLS.pdf`

This project focuses on public-key cryptography, secure key exchange, digital signatures, certificates, PKI concepts, file encryption, and TLS security.

Topics demonstrated include:

- RSA key generation and encryption
- RSA-OAEP encryption and decryption
- Manual RSA calculations
- Diffie-Hellman key exchange
- Digital signatures
- Signature verification and tamper detection
- X.509 self-signed certificates
- Certificate inspection
- Certificate-chain analysis
- GPG public-key encryption
- TLS cipher-suite inspection
- Identification of deprecated or weak cryptographic algorithms
